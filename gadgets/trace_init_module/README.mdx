# trace_init_module

The trace_init_module gadget emits events when processes invoke the `init_module()` or `finit_module()` syscalls to load kernel modules.

**Syscalls traced:**
- `init_module(module_image, len, param_values)` - loads a module from a memory buffer
- `finit_module(fd, param_values, flags)` - loads a module from a file descriptor

This gadget captures:
- For `init_module`: module size (`len`) and parameters (`param_values`)
- For `finit_module`: file descriptor (`fd`), resolved filepath, flags, and parameters (`param_values`)

**Note:** The `module_image` parameter from `init_module` is intentionally not captured.

## Requirements

- Minimum Kernel Version : 5.4

## Flags

### `--pid`

Show only events generated by processes with this pid

Default value: ""

### `--uid`

Show only events generated by processes with this uid

Default value: ""

## Guide

`trace_init_module` traces kernel module loading, capturing both the
`init_module(2)` and `finit_module(2)` syscalls. This is useful for spotting
unexpected module loads on a host or inside privileged containers.

Load a module to generate an event. `insmod` uses `init_module(2)` (the module
image is passed as a buffer, so `LEN` is populated), while `modprobe` typically
uses `finit_module(2)` (the module is passed by file descriptor, so `FD` and the
resolved `FILEPATH` are populated):

```bash
$ sudo ig run ghcr.io/inspektor-gadget/gadget/trace_init_module:%IG_TAG%
RUNTIME.CONTAINERNAME   COMM     PID     TID     SYSCALL        LEN    FD   FILEPATH        FLAGS   PARAM_VALUES
                        insmod   1234    1234    init_module    4096                                foo=bar
```

The gadget-specific columns are:

- `SYSCALL`: the syscall used to load the module — `init_module` or
  `finit_module`.
- `LEN`: the module image length in bytes (`init_module` only).
- `FD`: the file descriptor the module was loaded from (`finit_module` only).
- `FILEPATH`: the path resolved from `FD` (`finit_module` only).
- `FLAGS`: the flags passed to `finit_module`.
- `PARAM_VALUES`: the module parameter string passed to the syscall (may be
  truncated).

```bash
$ sudo ig run trace_init_module:%IG_TAG%
RUNTIME.CONTAINERNAME COMM  PID   TID   LEN  PARAM_VALUES
...                  insmod 1234  1234  4096 foo=bar
```
